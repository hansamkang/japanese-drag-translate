Privacy Policy

Japanese Drag Translate

Last updated: June 1, 2026

Japanese Drag Translate is a Chrome extension that helps users quickly understand selected Japanese text while studying or reading web pages. It is not a full-page translation tool. It only translates the Japanese text that the user selects or drags.

Information the Extension Processes

When you select or drag Japanese text on a web page, the extension may process that selected text in order to provide a Korean translation popup.

The extension does not collect your name, email address, account information, payment information, browsing history, or full page content.

Translation Services

To provide translations, the selected Japanese text may be sent to external translation services:

  • Google Translate service endpoint at https://translate.googleapis.com/
  • MyMemory Translation API at https://api.mymemory.translated.net/

These services receive the text that you selected for translation. Please review the privacy practices of those services if you need more information about how they handle requests.

Naver Japanese Dictionary Link

The Naver Japanese Dictionary feature is not an API integration. The extension provides a search link that opens only when you click the Naver Dictionary button. If you click that button, the selected text is included in the search URL and opened in Naver Japanese Dictionary.

Recommendations and Ads

The extension may show a small recommendation or advertisement area at the bottom of the translation popup. This data comes from the extension's local ads.json file.

The extension does not load external advertising scripts, tracking pixels, or third-party ad SDKs.

Data Storage

The extension does not store selected text, translations, or user profiles on our servers.

Japanese reading assistance is generated locally in the browser using bundled dictionary files and is not sent to an external reading API.

Data Sharing and Sale

We do not sell user data. We do not share user data with advertisers or data brokers.

Selected text may be transmitted only to the translation services listed above when needed to provide the translation feature.

Security

The extension is designed to keep its behavior simple and limited to the selected text translation workflow. It does not inject external scripts from a CDN and does not use external advertising scripts.

Changes to This Policy

This policy may be updated when the extension's features or data handling practices change. The latest version will be published on this page.
