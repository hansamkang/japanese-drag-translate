# 일본어 드래그 번역

영문 프로젝트명: `japanese-drag-translate`

일본어를 공부하면서 웹페이지의 모르는 단어나 문장을 빠르게 확인하기 위한 Chrome 확장 프로그램입니다.

이 확장 프로그램은 웹페이지 전체를 번역하는 도구가 아닙니다. 사용자가 직접 드래그한 일본어 부분만 한국어 번역과 히라가나 읽는법으로 보여주는 학습 보조 도구입니다.

예:

```text
放送
ほうそう
방송

海外
かいがい
해외
```

## 주요 기능

* 사용자가 드래그한 일본어 텍스트 감지
* 선택한 부분만 한국어 번역 팝업으로 표시
* 일본어 단어와 문장의 읽는법을 히라가나로 표시
* 읽는법은 확장 프로그램에 포함된 로컬 사전 파일로 브라우저 안에서 처리
* 외부 읽기 API 사용 없음
* 웹페이지 전체 번역 없이 읽기 흐름 유지
* 네이버 일본어 사전 링크 제공
* 선택한 단어나 문장 복사
* 팝업 하단 광고 영역 표시

## 기술 구성

* Chrome Extension Manifest V3
* Vanilla JavaScript
* Content Script 기반 팝업 UI
* Background Service Worker 기반 번역 요청
* 로컬 `kuromoji.js` 사전 기반 요미카타 분석

## 설치 방법

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 클릭합니다.
4. `japanese-drag-translate` 폴더를 선택합니다.

## 폴더 구조

* `manifest.json`: Chrome 확장 프로그램 설정 파일
* `content.js`: 웹페이지에서 드래그를 감지하고 팝업을 표시하는 파일
* `background.js`: 번역 API 요청을 처리하는 파일
* `style.css`: 팝업 디자인 파일
* `ads.json`: 팝업 하단 광고 데이터 파일
* `icons/`: 확장 프로그램 아이콘 파일
* `vendor/kuromoji/`: 히라가나 읽는법 표시를 위한 로컬 분석 라이브러리와 사전 파일
